## 이럴 때 쓰세요

- 매주 반복하는 엑셀·파일 작업을 **자동으로** 처리하고 싶을 때
- 엑셀 수식이나 간단한 스크립트가 필요한데 **코딩을 잘 모를 때**
- 오류 메시지의 뜻을 알고 싶을 때

## 효과

| | AI 없이 | AI 활용 (예상) |
|---|---|---|
| 소요 시간 | 매주 같은 작업 1시간 반복 | 스크립트 만들기 1시간(처음 1번) → 이후 매주 1분 |
| 결과물 | 손으로 하다 실수 발생 | 같은 결과를 일정하게 |

![코딩을 몰라도 스크립트를 만들 수 있습니다](../assets/p04-6-coding.png)

## 프롬프트: 비개발자용 스크립트

```text
나는 코딩을 거의 모르는 ______(직무)야. 아래 작업을 자동으로 하는 방법을 알려 줘.

[내 환경] 운영체제: ______ / 사용 프로그램: ______ / 파이썬 설치 여부: ______
[지금 하는 작업] ______
[원하는 결과] ______

[조건]
1. 가장 쉬운 방법부터 알려 줘 (엑셀 기능 → 수식 → 스크립트 순서로 고려)
2. 스크립트라면 실제로 바꾸기 전에 결과를 미리 보여 주는 "미리 보기" 모드를 넣어 줘
3. 원본 파일은 절대 덮어쓰지 말고 새 파일로 저장해 줘
4. 실행 방법을 처음 해 보는 사람 기준으로 단계별로 설명해 줘
```

## 입력 예시

```text
나는 코딩을 거의 모르는 영업지원 담당자야.
[내 환경] 운영체제: 윈도우 11 / 사용 프로그램: 엑셀 / 파이썬 설치 여부: 모름
[지금 하는 작업] 매주 월요일, 지점 5곳에서 받은 엑셀 파일(같은 양식)을 열어서
                하나의 시트로 복사해 붙이고, 지점 이름 열을 추가함
[원하는 결과] 폴더에 파일 5개를 넣으면 합쳐진 파일 하나가 자동으로 만들어짐
```

## 결과 예시

설명을 위해 작성한 예시입니다.

```text
가장 쉬운 방법은 엑셀의 "데이터 가져오기(파워 쿼리) → 폴더에서" 기능입니다.
코딩 없이 폴더 안의 파일을 합칠 수 있고, 다음 주부터는 "모두 새로 고침"만 누르면 됩니다.

[단계]
1. 새 엑셀 파일 → 데이터 탭 → 데이터 가져오기 → 파일에서 → 폴더에서
2. 지점 파일 5개가 있는 폴더 선택 → "결합 및 변환"
3. 파일 이름 열(Source.Name)을 "지점"으로 이름 변경
4. 닫기 및 로드

파이썬 스크립트가 필요하다면 별도로 알려 드릴게요.
```

이처럼 **"가장 쉬운 방법부터"**라고 요청하면, 코딩 없이 해결되는 방법을 먼저 알려 주는 경우가 많습니다.

## 오류가 났을 때 프롬프트

```text
아래 코드를 실행했더니 오류가 났어.
[내가 실행한 방법] ______
[오류 메시지 전체]
______
원인을 쉬운 말로 설명하고, 고친 코드를 전체로 다시 보여 줘.
```

## 더 잘 쓰는 팁

- **오류 메시지는 전체를 복사**해 붙여 넣으세요. 일부만 주면 원인을 찾기 어렵습니다.
- 처음 실행은 **복사본 파일**로 시험합니다.
- 잘 동작하는 스크립트는 "이 코드가 하는 일을 주석으로 설명해 줘"로 정리해 두면 나중에 고치기 쉽습니다.

## 주의할 점

- 개인정보·회사 기밀이 담긴 실제 파일 대신 **양식만 같은 가짜 데이터**로 질문합니다.
- 파일을 지우거나 옮기는 코드는 백업 후 미리 보기 모드로 먼저 실행합니다.
- 비밀번호·API 키를 코드나 프롬프트에 넣지 않습니다.
