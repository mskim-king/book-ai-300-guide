> 📅 **최종 확인**: 2026-11-21

글뿐 아니라 **그림, 영상, 음성**도 AI로 만들 수 있습니다. 발표 자료의 삽화, 홍보 이미지, 짧은 안내 영상, 내레이션 등을 디자이너 없이 빠르게 만들 수 있습니다.

## 요약

- 대화형 AI 대부분이 **이미지 만들기**를 지원합니다. 가장 쉬운 시작점입니다.
- 이미지 프롬프트는 **대상·스타일·구도·분위기·용도** 다섯 가지를 적으면 결과가 좋아집니다.
- 상업적으로 쓸 때는 **저작권·초상권·서비스 이용약관**을 먼저 확인합니다.

## 언제 쓰나

| 유형 | 예시 |
|---|---|
| 이미지 | 발표 자료 삽화, 블로그 대표 이미지, 아이콘, 포스터 시안 |
| 영상 | 짧은 제품 소개 영상, 교육용 설명 영상 시안 |
| 음성 | 안내 내레이션, 회의 녹음을 글로 받아 적기, 음성으로 AI와 대화 |

## 대표 도구

| 유형 | 도구 예시 | 시작 방법 |
|---|---|---|
| 이미지 | 대화형 AI의 이미지 생성(ChatGPT, Gemini 등), Midjourney, Ideogram, Adobe Firefly | 대화창에서 "이미지로 만들어 줘" |
| 영상 | 대화형 AI·전문 서비스의 영상 생성 기능 | 짧은 장면 단위로 시작 |
| 음성 | 대화형 AI의 음성 대화, 녹음 받아쓰기 기능 | 앱의 음성 모드 |

> 이 분야는 도구와 기능이 특히 빠르게 바뀝니다. 최신 도구는 09장 「최신 동향」에서 다룹니다.

## 바로 쓰는 활용 예시

### 예시 1. 발표 자료 삽화

```text
발표 자료에 넣을 삽화를 만들어 줘.
- 대상: 여러 부서 사람들이 하나의 화면을 보며 협업하는 모습
- 스타일: 단순한 평면 일러스트, 파란색·흰색 위주
- 구도: 가로형(16:9), 오른쪽에 제목을 넣을 빈 공간
- 분위기: 밝고 전문적인
- 넣지 말 것: 글자, 회사 로고
```

### 예시 2. 이미지 프롬프트를 AI에게 맡기기

```text
"친환경 텀블러 신제품" 홍보용 SNS 이미지를 만들려고 해.
이미지 생성 AI에 넣을 프롬프트를 스타일이 다른 것으로 3개 만들어 줘.
각 프롬프트에 대상·스타일·구도·분위기·용도를 모두 넣어 줘.
```

### 예시 3. 회의 녹음 → 회의록

```text
(녹음 파일을 올리거나 받아쓰기 결과를 붙여 넣은 뒤)
1. 말한 사람별로 핵심 발언을 정리해 줘.
2. 결정 사항과 할 일을 표로 정리해 줘.
3. 받아쓰기가 불분명해 보이는 부분은 [확인 필요]로 표시해 줘.
```

## 이미지 도구별 팁

| 도구 | 잘 맞는 일 | 팁 |
|---|---|---|
| 대화형 AI 이미지 생성 | 빠른 시안, 대화로 고치기 | "구도는 그대로, 색만 바꿔 줘"처럼 대화로 여러 번 다듬기 |
| Midjourney | 예술적인 일러스트, 콘셉트 아트, 분위기 이미지 | 스타일 단어(수채화, 시네마틱 등)를 구체적으로 |
| Ideogram | 이미지 안에 글자가 들어가는 포스터·배너 | 넣을 문구를 따옴표로 정확히 적기 |
| Adobe Firefly | 상업적 사용을 염두에 둔 이미지 | 회사 홍보물이라면 이용 조건을 먼저 확인 |

## 이미지 프롬프트 5요소

| 요소 | 예시 |
|---|---|
| 대상 | 노트북으로 일하는 30대 직장인 |
| 스타일 | 수채화풍 / 3D 렌더링 / 평면 일러스트 / 실사 사진풍 |
| 구도 | 정면, 위에서 내려다본, 가로형 16:9, 여백 위치 |
| 분위기 | 따뜻한 오후 햇살, 차분한, 활기찬 |
| 용도 | 블로그 대표 이미지, 슬라이드 배경, 포스터 |

[[TIP("요령: 한 번에 다 바꾸지 않기")]]

결과가 마음에 들지 않으면 처음부터 다시 쓰지 말고 **한 가지씩** 바꿔 달라고 하세요. 예: "구도는 그대로 두고 색만 주황색 계열로 바꿔 줘." 원하는 결과에 더 빨리 다가갑니다.

[[/TIP]]

## 주의할 점

- **실존 인물·유명 캐릭터·상표**를 흉내 낸 이미지는 만들지 않습니다.
- 상업적으로 쓸 때는 각 서비스의 **이용약관과 저작권 정책**을 확인합니다.
- AI로 만든 이미지·영상은 필요하면 "AI로 생성함"을 밝힙니다.
- 다른 사람의 목소리를 흉내 내는 음성은 만들지 않습니다.
- 회의 녹음은 참석자의 동의를 받고, 민감한 회의는 외부 AI에 올리지 않습니다.
