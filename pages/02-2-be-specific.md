> 📅 **최종 확인**: 2026-11-21

"잘 써 줘", "깔끔하게 정리해 줘"처럼 모호한 요청을 받으면 AI는 **가장 무난한 답**을 내놓습니다. 원하는 결과를 얻으려면 모호한 말을 **확인할 수 있는 조건**으로 바꿔야 합니다.

## 요약

- 모호한 형용사("좋게", "간단히")를 **숫자·대상·기준**으로 바꿉니다.
- 하지 말아야 할 것보다 **해야 할 것**을 알려 줍니다.
- 이유를 함께 알려 주면 AI가 조건을 더 잘 지킵니다.

## 모호한 말을 조건으로 바꾸기

| 모호한 요청 | 구체적인 요청 |
|---|---|
| 간단하게 요약해 줘 | 3줄로, 한 줄에 40자 이내로 요약해 줘 |
| 쉽게 설명해 줘 | 중학생도 이해할 수 있게, 전문 용어는 풀어서 설명해 줘 |
| 깔끔하게 정리해 줘 | 항목·담당자·마감일 3열 표로 정리해 줘 |
| 좋은 제목 만들어 줘 | 20자 이내, 숫자를 넣은 제목 후보 5개를 만들어 줘 |
| 전문적으로 써 줘 | 임원 보고용으로, 결론을 먼저 쓰고 근거는 3개로 써 줘 |

구체적인 조건을 만드는 질문은 다음 다섯 가지입니다.

1. **누가 읽나?** (대상: 고객, 임원, 신입사원, 초등학생)
2. **얼마나?** (분량: 3줄, 500자, 슬라이드 5장)
3. **어떤 모양으로?** (형식: 표, 목록, 이메일, 대본)
4. **어떤 말투로?** (어조: 격식체, 친근한 말투, 개조식)
5. **무엇을 꼭 넣고, 무엇을 빼나?** (포함·제외 조건)

## 나쁜 예 → 좋은 예

**❌ 모호한 요청**
```text
신제품 출시 안내 메일 좋게 써 줘.
```

**✅ 구체적인 요청**
```text
기존 고객에게 보낼 신제품 출시 안내 메일을 써 줘.

- 제품: 업무용 일정 관리 앱 '플랜온' 2.0
- 핵심 변경: 팀 공유 캘린더, 모바일 알림 개선
- 대상: 1년 이상 사용한 기존 고객
- 분량: 본문 5문장 이내
- 어조: 정중하지만 딱딱하지 않게
- 꼭 넣을 것: 기존 고객 20% 할인 쿠폰 (11월 30일까지)
- 마지막 줄: 문의 연락처 자리 [연락처]로 비워 두기
```

## "하지 마" 대신 "이렇게 해"

하지 말아야 할 것만 말하면 AI는 무엇을 해야 할지 모릅니다. 원하는 방향을 직접 말하는 편이 효과적입니다.

| 덜 효과적 | 더 효과적 |
|---|---|
| 너무 길게 쓰지 마 | 200자 이내로 써 줘 |
| 어려운 말 쓰지 마 | 일상에서 쓰는 쉬운 단어로 써 줘 |
| 목록으로 쓰지 마 | 이어지는 문단 2개로 써 줘 |

## 이유를 함께 알려 주기

조건만 주는 것보다 **왜 그 조건이 필요한지** 알려 주면 AI가 비슷한 상황까지 알아서 맞춥니다.

```text
문장을 짧게 써 줘. 이 글은 스마트폰 알림으로 보여서 한 화면에 다 보여야 해.
```

이유를 알려 주면 AI는 단순히 문장만 줄이는 것이 아니라, 핵심을 앞에 두고 불필요한 인사말을 빼는 식으로 목적에 맞게 조정합니다.

[[TIP("요령")]]

처음부터 조건을 완벽하게 쓰기 어렵다면 AI에게 먼저 물어보게 하세요.

"이 작업을 잘하려면 나에게 어떤 정보가 더 필요한지 질문부터 해 줘."

AI가 질문한 항목에 답하다 보면 자연스럽게 구체적인 프롬프트가 완성됩니다.

[[/TIP]]

| 모호한 요청 | 내가 바꾼 요청 |
|---|---|
| 회의 안건 정리해 줘 | |
| 공지문 깔끔하게 써 줘 | |
| 이 데이터 분석해 줘 | |

**예시 답 (첫 번째)**: "팀원 6명이 회의 전에 읽을 수 있게, 안건 4개를 우선순위 순서로 번호 목록으로 정리해 줘. 안건마다 결정할 내용 한 줄과 예상 소요 시간을 붙여 줘."
