문서·노트 AI는 **내가 올린 자료 안에서만** 답합니다. 웹이나 AI의 기억에 기대지 않기 때문에 환각이 적고, 답마다 내 문서의 어느 부분이 근거인지 보여 줍니다.

## 요약

- 대표 도구는 **NotebookLM**입니다. 대화형 AI의 **프로젝트**에 파일을 넣어 비슷하게 쓸 수도 있습니다.
- 보고서·논문·매뉴얼·강의 자료처럼 **정해진 자료를 깊이 이해**해야 할 때 씁니다.
- 자료를 **음성 해설(오디오 개요)** 로 만들어 이동 중에 들을 수도 있습니다.

## 언제 쓰나

- 수십 쪽짜리 보고서나 규정집에서 필요한 내용을 찾을 때
- 여러 문서를 비교해야 할 때 (예: 작년 계획서와 올해 계획서)
- 새 업무·새 분야를 자료로 빠르게 공부할 때
- 회사 매뉴얼을 질문-답변 형식으로 만들 때

## 검색형 AI와 다른 점

| | 검색·리서치 AI | 문서·노트 AI |
|---|---|---|
| 답의 근거 | 웹 페이지 | 내가 올린 자료 |
| 출처 표시 | 웹 링크 | 내 문서의 해당 부분 |
| 잘하는 일 | 최신 정보, 넓게 찾기 | 정해진 자료를 깊게 분석 |
| 함께 쓰는 법 | 자료를 찾아서 → | → 문서 AI에 넣고 분석 |

## 바로 쓰는 활용 예시

### 예시 1. 두꺼운 보고서 핵심 파악

```text
(보고서 PDF를 올린 뒤)
1. 이 보고서의 핵심 주장 5가지를 정리해 줘.
2. 각 주장의 근거가 되는 부분을 인용해 줘.
3. 우리 팀(마케팅)과 관련된 내용만 따로 모아 줘.
```

### 예시 2. 문서 비교

```text
(작년·올해 사업계획서 두 개를 올린 뒤)
두 문서를 비교해서 [항목 | 작년 | 올해 | 바뀐 점] 표로 정리해 줘.
새로 생긴 항목과 없어진 항목은 따로 표시해 줘.
```

### 예시 3. 공부용 질문 만들기

```text
(교육 자료를 올린 뒤)
이 자료를 처음 공부하는 신입사원을 위해
1. 꼭 알아야 할 용어 10개와 쉬운 설명
2. 이해도를 확인하는 퀴즈 5문제 (정답과 근거 위치 포함)
를 만들어 줘.
```

## 도구별 팁

### NotebookLM
- 하나의 노트북에 **주제가 같은 자료끼리** 모아 두세요. 주제가 섞이면 답도 섞입니다.
- 답변의 **인용 표시를 누르면** 원래 문서의 해당 부분으로 이동합니다. 중요한 답은 꼭 눌러서 확인하세요.
- **오디오 개요(Audio Overview)** 는 자료를 두 사람이 대화하듯 설명하는 음성으로 만들어 줍니다. 출퇴근길에 자료를 미리 훑어볼 때 좋습니다. 지원 언어와 길이는 공식 안내를 확인하세요.
- 노트북에 넣을 수 있는 자료 수에 한도가 있습니다. 요금제에 따라 다릅니다.

### 대화형 AI의 프로젝트
- ChatGPT·Claude의 프로젝트에 파일을 넣어 두면 비슷하게 쓸 수 있습니다.
- 다만 웹 검색이나 AI의 기억이 섞일 수 있으니 "**올린 자료에 있는 내용만으로 답해 줘**"라고 지시합니다.

[[TIP("요령: 검색형 + 문서형 조합")]]

① 검색형 AI로 믿을 만한 자료(공식 보고서, 논문)를 찾고 → ② 그 원문을 문서 AI에 넣어 분석하면, 넓게 찾기와 깊게 읽기를 모두 할 수 있습니다.

[[/TIP]]

## 주의할 점

- 회사 내부 문서를 올려도 되는지 보안 규정을 먼저 확인합니다.
- 스캔한 PDF는 글자를 잘못 읽을 수 있습니다. 표와 숫자는 원문과 대조합니다.
- 자료에 없는 내용을 물으면 엉뚱한 답이 나올 수 있습니다. "자료에 없으면 없다고 답해 줘"를 덧붙입니다.
