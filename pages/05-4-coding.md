> 📅 **최종 확인**: 2026-11-21

코딩 AI는 **코드를 쓰고, 고치고, 직접 실행해 보는** AI입니다. 개발자가 아니어도 엑셀 반복 작업, 파일 정리, 간단한 데이터 처리 같은 일을 자동화할 수 있습니다.

## 요약

- **비개발자**는 대화형 AI에게 짧은 스크립트·엑셀 수식을 받아 쓰는 것으로 시작합니다.
- **개발자**는 Claude Code, Cursor, GitHub Copilot 같은 **코딩 에이전트**로 여러 파일을 한 번에 수정합니다.
- 어떤 경우든 **결과를 실행해 확인**하고, 중요한 파일은 **백업 후** 실행합니다.

## 언제 쓰나

| 사용자 | 예시 |
|---|---|
| 비개발자 | 엑셀 수식, 여러 파일 이름 한 번에 바꾸기, CSV 정리, 간단한 웹 화면 |
| 개발자 | 기능 추가, 버그 수정, 테스트 작성, 코드 설명, 리팩터링 |

## 대표 도구

| 도구 | 쓰는 곳 | 특징 |
|---|---|---|
| 대화형 AI (ChatGPT, Claude, Gemini) | 웹·앱 대화창 | 코드 작성·설명. 비개발자 시작용으로 좋음 |
| Claude Code | 터미널, IDE, 웹 | 프로젝트 전체를 읽고 여러 파일을 고치는 에이전트 |
| Cursor | AI 기능이 들어간 코드 편집기 | 편집기 안에서 코드 제안·수정, 클라우드 에이전트 |
| GitHub Copilot | 코드 편집기, GitHub | GitHub 이슈·PR과 함께 쓰기 편함 |
| Codex | 터미널, 웹 | OpenAI의 코딩 에이전트 |

> 요금·기능은 자주 바뀝니다. 공식 사이트에서 확인하세요.

## 바로 쓰는 활용 예시

### 예시 1. 엑셀 수식 (비개발자)

```text
엑셀 A열에 주문일(2026-11-03 형식), B열에 금액이 있어.
C열에 "주문일이 이번 달이고 금액이 10만 원 이상이면 '중점', 아니면 공란"이
나오게 하는 수식을 알려 줘.
수식의 각 부분이 무슨 뜻인지도 설명해 줘.
```

### 예시 2. 파일 정리 스크립트 (비개발자)

```text
윈도우 PC의 "다운로드" 폴더에 있는 파일을 확장자별 폴더(PDF, 이미지, 엑셀, 기타)로
옮기는 파이썬 스크립트를 만들어 줘.
- 실제로 옮기기 전에 옮길 목록만 보여 주는 "미리 보기" 모드를 먼저 넣어 줘.
- 같은 이름의 파일이 있으면 덮어쓰지 말고 이름 뒤에 번호를 붙여 줘.
- 실행 방법을 처음 해 보는 사람 기준으로 단계별로 알려 줘.
```

### 예시 3. 코딩 에이전트에게 일 맡기기 (개발자)

```text
로그인 실패 시 에러 메시지가 영어로 나오는 문제를 고쳐 줘.
1. 먼저 관련 파일을 찾아서 원인을 설명해 줘. (아직 고치지 마)
2. 내가 확인하면 한국어 메시지로 고치고, 기존 테스트를 실행해 줘.
3. 새 테스트도 하나 추가해 줘.
```

[[TIP("요령: 계획 먼저, 수정은 나중에")]]

코딩 에이전트에게는 "**먼저 계획을 설명하고 내가 확인하면 고쳐 줘**"라고 요청하세요. 엉뚱한 파일을 고치는 일을 막을 수 있고, 무엇이 바뀌는지 이해한 상태에서 진행할 수 있습니다.

[[/TIP]]

## 도구별 팁

### 대화형 AI
- 오류가 나면 **오류 메시지 전체를 복사해** 붙여 넣으세요. "안 돼요"보다 훨씬 빨리 해결됩니다.
- 내 환경(윈도우/맥, 엑셀 버전, 파이썬 설치 여부)을 알려 주면 맞는 방법을 알려 줍니다.

### Claude Code
- 프로젝트 폴더에 **CLAUDE.md** 파일을 두고 규칙(코드 스타일, 테스트 방법)을 적어 두면 매번 설명하지 않아도 됩니다.
- 큰 작업은 작은 단계로 나눠 맡기고, 단계마다 결과를 확인합니다.

### Cursor
- 편집기 안에서 바로 코드를 선택하고 질문하거나 고칠 수 있어, 코드를 보면서 작업하는 방식에 맞습니다.

### GitHub Copilot
- 이미 GitHub로 협업하고 있다면 이슈·PR 흐름과 함께 쓰기 편합니다.

## 주의할 점

- AI가 만든 코드는 **반드시 실행해 결과를 확인**합니다. 그럴듯해 보여도 틀릴 수 있습니다.
- 파일을 지우거나 옮기는 코드는 **백업 후**, 미리 보기 모드로 먼저 실행합니다.
- 비밀번호·API 키를 코드나 프롬프트에 그대로 넣지 않습니다.
- 회사 코드를 외부 AI에 올려도 되는지 보안 규정을 확인합니다.
