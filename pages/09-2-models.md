AI 도구 안에는 **모델**(LLM)이 들어 있습니다. 같은 서비스라도 어떤 모델을 쓰느냐에 따라 속도, 정확도, 비용이 달라집니다. 모델 이름과 버전은 몇 달마다 바뀌므로, 이 페이지는 **모델을 고르고 평가하는 기준**을 중심으로 다룹니다.

## 요약

- 모델은 크게 **빠르고 가벼운 모델**과 **느리지만 깊이 생각하는 모델**로 나뉩니다.
- 새 모델이 나와도 **내 업무 시험 세트**로 비교한 뒤 바꿉니다.
- 모델 이름보다 **내 일에서 어떤 결과를 내는가**가 중요합니다.

## 모델의 종류

| 종류 | 특징 | 어울리는 일 |
|---|---|---|
| 가볍고 빠른 모델 | 답이 빠르고 비용이 낮음 | 간단한 요약, 분류, 번역, 대량 처리 |
| 범용 모델 | 속도와 품질의 균형 | 대부분의 업무, 글쓰기, 분석 |
| 추론(생각하는) 모델 | 답하기 전에 오래 생각, 느리지만 정확 | 복잡한 분석, 수학·코딩, 여러 조건 판단 |
| 멀티모달 모델 | 글·이미지·음성을 함께 이해 | 사진 속 표 읽기, 화면 캡처 분석 |
| 오픈 모델 | 직접 설치해 쓸 수 있음 | 데이터를 외부로 보내기 어려운 환경 |

주요 모델 계열로는 OpenAI의 GPT 계열, Anthropic의 Claude 계열, Google의 Gemini 계열이 있고, 직접 설치해 쓸 수 있는 오픈 모델도 여러 회사에서 공개하고 있습니다. 구체적인 버전과 성능은 빠르게 바뀌므로 각 회사의 공식 발표를 확인하세요.

## 내 업무 시험 세트 만들기

새 모델이 나올 때마다 같은 질문으로 비교하면 감이 아니라 **결과로** 판단할 수 있습니다.

```text
[내 업무 시험 세트 예시 — 5문항]
1. 실제 회의 메모(가명처리) → 회의록 정리 (04-2 레시피)
2. 고객 문의 10건 분류 (정답을 미리 정해 둠)
3. A4 2쪽 보고서 → 임원용 3줄 요약
4. 엑셀 수식 만들기 (정답 수식 있음)
5. 한국어 이메일 → 영어 번역 (용어집 포함)
```

| 비교 기준 | 측정 방법 |
|---|---|
| 정확도 | 정답이 있는 문항(2, 4번)의 맞은 수 |
| 품질 | 사람이 1~5점 평가 (1, 3, 5번) |
| 속도 | 답이 나오기까지 걸린 시간 |
| 비용 | 요금제·사용량 기준 |

[[TIP("요령: 바꾸기 전에 나란히 써 보기")]]

새 모델로 바로 바꾸지 말고, 1~2주 동안 **기존 모델과 같은 일을 나란히** 시켜 보세요. 특히 자동화(07-3)에 쓰는 프롬프트는 모델이 바뀌면 결과 형식이 달라질 수 있어 꼭 시험이 필요합니다.

[[/TIP]]
