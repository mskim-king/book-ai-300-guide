## 같은 유형 안에서 고르는 기준

| 기준 | 확인할 질문 |
|---|---|
| 보안 | 회사에서 허용한 도구인가? 입력이 학습에 쓰이지 않는 요금제인가? |
| 연동 | 지금 쓰는 메일·문서·메신저와 연결되는가? |
| 한국어 | 내 업무의 한국어 결과 품질이 충분한가? (시험 세트로 확인, 09-2) |
| 비용 | 무료로 충분한가? 팀 요금제가 필요한가? |
| 관리 | 팀원 계정·권한을 관리할 수 있는가? |

| 홍보물 | 대화형(문구) → 이미지 AI(시안) → 사람(최종 디자인) |
