AI 도구는 매달 새로 나오고 이름도 자주 바뀝니다. 그래서 이 장은 도구를 **이름이 아니라 유형으로** 나눠 설명합니다. 유형을 알면 새 도구가 나와도 "아, 이건 검색형 AI구나" 하고 바로 쓰임새를 알 수 있습니다.

| 유형 | 한 줄 설명 | 이런 일에 |
|---|---|---|
| 대화형 AI | 무엇이든 묻고 시키는 만능 비서 | 글쓰기, 요약, 기획, 분석 |
| 검색·리서치 AI | 웹을 찾아 출처와 함께 답함 | 최신 정보, 시장 조사, 사실 확인 |
| 문서·노트 AI | 내가 준 자료 안에서만 답함 | 보고서·논문·매뉴얼 분석, 학습 |
| 코딩 AI | 코드를 쓰고 고치고 실행함 | 업무 자동화 스크립트, 개발 |
| 이미지·영상·음성 AI | 그림·영상·음성을 만듦 | 발표 자료, 홍보물, 콘텐츠 제작 |
| 업무 자동화 도구 | 여러 서비스를 이어 반복 작업을 자동 실행 | 메일 분류, 보고서 자동 작성 |

[[TIP("읽는 방법")]]

각 페이지는 **① 언제 쓰나 → ② 대표 도구 → ③ 바로 쓰는 활용 예시(프롬프트) → ④ 도구별 팁 → ⑤ 주의할 점** 순서로 되어 있습니다. 급하면 ③의 프롬프트만 복사해서 써도 됩니다.

[[/TIP]]

[[TIP("알려드립니다")]]

도구 이름, 기능 이름, 요금제는 자주 바뀝니다. 이 장의 내용은 각 페이지 위의 **최종 확인** 날짜 기준이며, 매 분기 다시 확인해 고칩니다. 요금과 사용 한도는 각 서비스의 공식 사이트에서 확인하세요.

[[/TIP]]
