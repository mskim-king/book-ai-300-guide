# 책 관리 사용법 (위키독스 목차에 포함되지 않음)

## 기본 흐름
1. `structure.yaml` 수정 (장·페이지 추가, 제목 변경)
2. `python generate.py --check` 로 미리 보기 → `python generate.py`
3. 생성된 페이지에 내용 작성 (브랜치 `draft/주제명` 에서)
4. Pull Request → `main` 에 merge → 위키독스 자동 반영

`main` 에 push 되면 GitHub Actions 가 2번을 대신 실행합니다.

## 페이지 템플릿
| 템플릿 | 용도 | structure.yaml 지정 |
|---|---|---|
| page | 일반 설명 페이지 | (기본값) |
| recipe | 프롬프트 레시피 | `template: recipe` |

## 상태 표시
🟡 작성 중 → 🔵 검토 중 → 🟢 완료  
`python generate.py --status` 로 전체 현황 확인, README 에 진행률 자동 표시.

## 자동 점검 (GitHub Actions)
| 워크플로 | 주기 | 하는 일 |
|---|---|---|
| 구조 자동 생성 | main push 시 | 페이지·TOC·README 생성 |
| 갱신 점검 | 매월 1일 | 완료 페이지 중 최종 확인 30일·재테스트 60일 경과 → Issue |
| 링크 검사 | 매월 15일 | 깨진 링크 → Issue |

수동 실행: `python check.py`

## 갱신 주기
- 매월: 09장 최신 동향, 월간 업데이트 노트, CHANGELOG 기록
- 분기: 05장 도구, 부록 도구 비교표 재확인, 레시피 재테스트

## 안전 규칙
- 이미 있는 페이지는 덮어쓰지 않음, structure.yaml 에서 뺀 파일은 "고아 파일"로 알림만
- 토큰·비밀번호는 저장소에 커밋 금지
- 예시에는 실제 개인정보·회사 기밀을 쓰지 않음
